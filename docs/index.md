# taiga-cli

A command-line client for [Taiga](https://taiga.io) whose output is designed to cost as few
tokens as possible when read by an AI agent, while staying pleasant for humans.

- **[User guide](user/index.md)**: install, log in, run commands, wire it into your agent.
- **[Developer guide](dev/index.md)**: set up a dev environment and contribute.
